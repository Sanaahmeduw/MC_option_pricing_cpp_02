# R Package: MonteCarloOptionPricing

> **Using C++ to develop R package for pricing European options with Monte Carlo simulation, featuring antithetic variates for variance reduction**

## 📋 Problem Overview

This project implements a Monte Carlo option pricing engine in R (C++ based R package) two key features:
1. **Call/Put selection** – Price either type of European option
2. **Antithetic variates** – Toggle variance reduction technique on/off

The package is then used in a comparative study running 1,000 simulations (with and without antithetic variates) to demonstrate the statistical properties of Monte Carlo option pricing.
